- 不新增求解循环，不提前实现证明图、路线/APRS 或完整并发。

## 实施语义与判断

数学回合定义为一次数学工作报告及其控制器审查完成后的权威迁移。传输重试、协议修复、工具续接、Meta 建议、GET、刷新与重连不独立增加数学回合。未完成或 unknown 的审查不取得数学进展。

新证据必须来自既有控制器接受且当前规格有效的证据。模型自报、仅改变文本、未被接受的异议及无关引理不重置计数。不能简单按 evidence_id 或审查 call_id 去重：新调用身份不等于数学内容新增。不能简单按覆盖根义务数计量全部进展：与开放根义务相关的有效中间证据也可能构成进展，本版以冻结规格中的结构化前提目标承接这类进展。

计数应与触发该计数的权威迁移在同一事务提交。恢复读取持久状态，不清零、不补发调用；回退、改名、重规划不自行清零。新证据的去重历史不能随无进展计数重置而消失。启用入口为可信服务端 `SHOWCASE_STAR_FEATURES.progress_scheduling=true`（同时启用 S03）或显式 SolverHarness config；HTTP 客户端不取得开关控制权。规格变化须区分旧证据失效与真实新增证据，不能以失效后重贴旧证据刷进度。

**用户已决议：受控结构化方法标识。** WorkUnit 的 `method_id` 仅接受 `direct`、`contradiction`、`induction`、`construction`、`computation`、`unknown`；大小写、别名、自由命名和缺失值归入统一 `unknown`。不新增分类器或方法本体。不同合法方法可探索，但共享原预算和整体停滞约束。

实施采用有限证据状态：首次满足的根义务，以及冻结 ProblemSpec 中明确沿 prerequisite/dependencies 通向尚未满足的根义务的辅助目标。后者只在其 WorkUnit 的现有审查给出有效 ACCEPT 后取得一次信用。普通自由文本引理不取得信用；这是有意保守的结构化边界，不宣称能自动识别任意自然语言中间定理的数学新颖性。

每个 `(目标义务 ID, method_id)` 累计无新增证据的失败，第二次触发局部阻断并转 Meta。相关新证据改变有效证据状态后允许新的尝试；无关目标的证据不会解锁已阻断动作。新证据重置全局连续无进展计数。首次取得证据的目标历史单调保留，回退或重新包装同一目标不再次取得信用。

连续三个无新证据数学回合触发停滞建议并进入既有 Meta。局部阻断后 Meta 可以授权重规划选择不同方法；继续相同阻断动作在实际派发前停止。整体停滞达到阈值后不再派发数学动作，保留 Meta 的有界停止/诊断。原 replan 上限、共享预算和 deadline 不变。若没有 Meta 端口则保持可审阅的 META_DECIDE，不自动新增调用。

## 验收与退出条件

| 行为组 | 可执行验收要求 |
| --- | --- |
| 版本与恢复 | 开关关闭无新行为；新 Run 冻结策略；旧 Run 无迁移；重读、重连不新增调用；计数持久化 |
| 数学回合与证据 | 三个无新证据回合触发；真实新证据重置连续计数；传输/修复不计回合；重复或无关材料不重置 |
| 动作阻断 | 第二次重复达到阈值；换措辞、改名、重规划不绕过；真正不同方法按确认合同处理 |
| 完成与资源 | 根义务完成直接走 S03 收尾；deadline、共享预算、unknown 与身份不重置；无资源时诚实停止 |
| 事务与退出 | CAS 冲突整次拒绝；事件与计数原子一致；Meta/回退/重规划无法无限续跑 |

每组先失败验收，再最小实现、聚焦检查与相关回归。阶段退出集中双轴审查，修复阻塞项后冻结源码，按[工程门禁](development-gates.md)运行最终检查。已有同源码成功证据可复用；源码 SHA 与纯文档交接 SHA 分开记录。

S04 工程退出与已通过的 S03 共同解除 F1/S07 工程前置。真实 provider、容量/SLA、自然题和数学效果保持未验证；不启动付费实验，不关闭 #146。
