## 行为及退出条件

1. 自然进展/停滞和 Agent 决策可触发同任务 serial ↔ population；初始选择不算切换。先持久化意图，冻结受影响新派发，等待已派发动作结算，再版本检查及原子建立 checkpoint 和目标状态。
2. Job/Run、冻结配置 hash、根账本/deadline、策略、进展计数不重置；保留路线谱系、实际采用来源和动作身份。只有已核验且仍适用的成果可进入目标执行。
3. unknown 不自动重发、不释放原预留，阻塞依赖切换；取消优先。崩溃后复用意图、checkpoint 与完成回执，不能再次派发已完成动作。旧 Run 没有权限合同则保持旧语义。
4. 公共 Job/API、报告和前端显示切换中、已切换、待复核，并保留安全摘要。提供带来源版本的合法串行 checkpoint，供 #176 干预使用；本票不实现自主干预。
5. 验收以公共 Job/API 到真实模型、持久状态和只读刷新为主；先保留一个失败见证，离线只补改变行为与难以自然触发的关键故障。自然模型不能稳定触发时，依无人值守合同记录两次有目的尝试及透明调整，开发接线和真实能力分开。
