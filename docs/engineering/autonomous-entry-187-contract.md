# #187 自主求解入口合同

2026-11-16，承接 #185、#186。问题是用户将不同维度的执行预设理解成需要手动选择的题目难度或架构能力。

## 设计与边界

默认服务入口 `faithful.solver_mode` 显示为「自主求解（推荐）」，解释按实际求解与检查反馈使用已配置能力。默认高级设置折叠。原生 select 分组为自主调度、资源与候选交付、调试与兼容；后者包括显式多路线与基础路径。高级设置说明这些是互斥预设，手选改变执行边界，不保证覆盖默认入口全部自主行为，可一键恢复推荐入口。

只更改前端展示，沿用现有模式、启用状态及提交参数；不新增独立预算/交付开关，不更改后端决策、预算、旧 Run 或 baseline。自主服务未启用时保持兼容入口与原 reference 名称，不能仅凭模式名承诺自主能力。沿用现有 Vue 组件与设计 token、原生 details/summary/select，不引入依赖。
