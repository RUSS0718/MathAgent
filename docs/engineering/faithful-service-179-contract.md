# #179 授权内自动经验记忆与撤销合同

日期：2026-11-14，退出口径更新于 2026-11-15（Asia/Shanghai）。状态：开发接线验收完成；父规格 #168，当前票 #179。唯一前置 #169 已关闭。执行遵循[接续合同](unattended-ticket-loop.md)与[工程门禁](development-gates.md)。

## 设计与边界

复用 FaithfulMemoryStore、会话注入同意、现有管理 API 及来源祖先链。经验为真实终态运行的有界观察，不是证明；可信 ProblemSpec domain 决定检索范围。关闭、清理或撤销后，每次后续模型派发及恢复都重新核验当前控制与来源，持久 advisory 和角色历史不能成为绕过通道。已发出请求不能撤回；审计记录保留，不改写有效数学账本。默认官方路径与 baseline 字节稳定。

Agent 可以采用或拒绝相关观察，检索、注入与决策分别留来源；不把注入本身冒认采纳。跨会话只有同所有者显式导入，读取时复核所有祖先有效性。继续和恢复沿用原 Run 身份、预算与 deadline，unknown 不自动重发。
