# #179 授权内自动经验记忆与撤销合同

日期：2026-11-14（Asia/Shanghai）。状态：实施中；父规格 #168，当前票 #179。实时核验唯一前置 #169 已关闭。执行遵循[接续合同](unattended-ticket-loop.md)与[工程门禁](development-gates.md)。

## 设计与边界

复用 FaithfulMemoryStore、会话注入同意、现有管理 API 及来源祖先链。经验为真实终态运行的有界观察，不是证明；可信 ProblemSpec domain 决定检索范围。关闭、清理或撤销后，每次后续模型派发及恢复都重新核验当前控制与来源，持久 advisory 和角色历史不能成为绕过通道。已发出请求不能撤回；审计记录保留，不改写有效数学账本。默认官方路径与 baseline 字节稳定。

Agent 可以采用或拒绝相关观察，检索、注入与决策分别留来源；不把注入本身冒认采纳。跨会话只有同所有者显式导入，读取时复核所有祖先有效性。继续和恢复沿用原 Run 身份、预算与 deadline，unknown 不自动重发。

| 编号 | 公共入口与断言 | 验证方式 |
| --- | --- | --- |
| C1 | 会话同意关闭时正常求解，但不自动记录或注入 | 复用现有公共 Job/API 检查 |
| C2 | 开启后真实终态观察自动记录，相关同域记录选用可追踪，经验保持 advisory_only | 少量真实普通输入、Run/Job/Attempt 与记忆来源；决策状态不冒充证明 |
| C3 | 同所有者显式导入，祖先撤销或禁用后不再使用 | 复用来源链公共反例与受影响回归 |
| C4 | 已载入经验的 Run 关闭、清理或撤销后，继续及重启恢复的后续请求不再包含失效经验 | 先保留失败见证，再运行公共反例；检查持久副本及角色上下文 |
| C5 | 用户能启用、关闭、导入、清理并理解生效范围 | 现有管理入口与普通浏览器；保留历史审计和有效账本 |
