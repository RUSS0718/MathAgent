# 对话式工作台集成合同（2026-11-12）

起点：`822069d`；目标工作树为主目录，分支 `feat/conversation-workbench`。
设计参考为用户指定 OpenDesign 项目的工作台、星图、主题及后端需求文档。
原型 SCENES 不进入 live 数据流。复用现有认证、CSRF、Job、SSE、详情和报告接口。
默认主页必须由新工作台取代；旧聊天主页及 Inspector 不再作为主页渲染，
保留会话、输入、运行详情和报告组件作为已有能力复用。

## 实施与退出条件

| 编号 | 要求 | 验证 |
| --- | --- | --- |
| C1 | SSE 终局后继续消费至 EOF；interrupt 可以结束观察；重连去重 | 传输测试 |
| C2 | 一个共享投影驱动时间顺序对话、动态计划、大小星图及筛选 | 投影单测、浏览器 |
| C3 | 来源仅以任务事实判定 fake/live；历史操作标记 replay；未知保持未知 | 投影单测 |
| C4 | 答案取详情/报告，不取终局说明；切视图不启动任务 | 浏览器及现有 Job 测试 |
| C5 | 新协作字段仅公开角色、步骤、版本、关联 ID 和允许公开的摘要 | 后端白名单测试、schema 测试 |
| C6 | 回退仅展示已失效/保留范围，不预告重算结果 | 后端测试 |
| C7 | 禁止将普通 resume 文本声称为已生效约束 | UI 禁用并解释；恢复控制单独保留 |

协作字段采用可选 `workbench`（version = `workbench-v1`），保持旧事件兼容。
线程身份绑定 run/plan/attempt/step；消息身份绑定持久 solver event。
没有已批准公开正文时只给分类摘要并声明内容未公开；不得直接投影模型回复、prompt 或隐藏推理。
不新增任意文本插话协议，不改变求解流程、预算或官方 baseline。
离线/fixture 验收不等于真实 provider 或数学能力验收。

公开边界：既有隐私测试禁止暴露 plan.objective 和模型报告。当前仅公开计划序号与状态，
数学标题/正文、回复正文、模型裁决依据和数学逐行 diff 仍需专门的公开摘要协议；
界面保持未公开提示。`evidence_chain` 仅含 ACCEPT 且 valid 的步骤标签，不能当作形式化证明。

旧草稿处理：2026-11-12 用户明确选择保留到可恢复归档，不集成未经审查的旧草稿。
