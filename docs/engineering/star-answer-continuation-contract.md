# STAR 工具额度与完整回答续接合同

状态：accepted。来源：2026-10-28 用户要求减少限制对完整答案输出的阻断。

## 目标与边界

工具调用额度只决定能否执行新的工具动作。额度已用满或为零时，只要仍有模型、HTTP、token 和时间额度，Solver Run 可以继续纯推理、消费已完成的工具回执、整理答案和整题审查。工具计数达到上限不再独立触发整次运行的 `partial_budget_exhausted`。

该决策更新此前“任一额度耗尽均阻断所有新动作”的规则，仅解除工具额度与模型派发的耦合。它适用于显式 Showcase / Solver Harness；官方 baseline、默认入口和默认模型预算不变。已消费的 v5 manifest、归档、失败结果和数学判定均不回写、不续跑。

取消、deadline、未知远端结果和隔离规则保持原合同。未知请求不自动重试，迟到用量只归入原 attempt。工具执行仍受原权限、唯一 S3 账本和累计额度约束。S4 最终答案身份、审查范围与文本绑定规则不变；工具拒绝或局部计算结果不能替代整题审查或数学证明。

## 行为合同

- 成功执行最后一次获准工具后，真实回执继续进入同一 Run 的模型会话，后续答案生成与整题审查可正常完成。
- 工具额度为零或已用满时，工具执行准入与唯一 S3 账本仍拒绝额外执行；不得计为成功计算、不得伪造回执或重置累计计数。
- 被拒绝的计算请求以未执行回执提供给模型。模型可在剩余额度内给出无需新增计算的推理或说明；拒绝本身不能被解释为审查通过。
- 取消、未知远端结果、模型 / HTTP / token 总额度及原始 deadline 仍遵循原合同；不新增无限重试或运行后自动提高限额。
- 返回内容必须区分完整答案、尚未解决和失败。不得把非空错误说明当作正常解答或把未审查答案标为已审查。
