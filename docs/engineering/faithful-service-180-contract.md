# #180 自主证明缓存与当前核验合同

复用 #178 普通输入生成目标及现有 S10 自动缓存接线，不新增模型调用、不改变经验记忆授权。仅可信 Lean 来源可入库，身份继续覆盖目标、假设、规格、环境和证明来源。显式会话缓存开关默认关闭。

命中通过原 Registry/根预算和 deadline 执行当前 Lean，旧回执不提供当前资格，缓存等级上限 L2；当前对应审核和范围独立决定资格。清理、漂移、停用和 unknown 不可恢复旧证明权威或自动重发。

本票补齐现有缓存审计的当前 Run/Attempt、核验状态及等级关联，并在既有会话缓存 UI 显示，允许从来源与当前回执区分历史证据。未命中、失效原因继续使用现有状态与审计。

验收先扩展现有真实 Lean 重验案例留红灯，再检查公共缓存 API/UI、普通输入真实来源及自然命中。真实模型场景未跑通保持失败或 not_run，按接续合同有界诊断；工程退出依 development-gates.md，真实能力边界保存在验收记录。官方 baseline 保持字节稳定，tests/test.md 禁止读取。

live01/02 未产生可信来源，live01 的 Lean 输出超过256KB；live03有针对性改为1MB输出上限，保持根预算，仍因不支持的形式化及预算耗尽失败。原运行均不追改。按无人值守接续合同停止新增真实调用，开发退出以既有可信身份、真实固定 Lean 两次独立执行和同根计账、28项缓存聚焦及3项受控浏览器、双轴复核和最终门禁为条件。普通输入的可信来源→自然命中→真实当前回执/UI、跨进程恢复保持未实证，转交#183；这不是完整服务或数学收益验收。
