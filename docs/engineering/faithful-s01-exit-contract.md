## 执行顺序与退出声明

先逐项检查已有证据，缺失行为先写失败验收，再最小实现、聚焦回归、差异审查和逻辑提交。流式恢复与浏览器验收可并行，修改范围隔离；最终集成后才执行唯一一次相关长门禁，不重复启动。

上述工程合同均有实际执行的可复现证据，并且审查无未处理问题时，才允许记录 S01 工程退出。已有测试名或旧报告不能替代新策略组合的实际执行。真实浏览器的受控 API 证据与真实跨进程后端证据分别说明，不能混称 provider-live。

真实 provider SLA、自然题、服务容量、费用和独立数学效果未在本合同中自动通过，分别保持 `not_run`、`unknown` 或 `unavailable`。这些能力结论不由离线工程退出推导；后续切片仅可依赖已满足的工程状态合同。
