# S06 基础输出模式合同

日期：2026-11-08。依据 #144 的 S06 合同、accepted implement-spec 与 #152 的基础开工范围；本轮不等同完整 F6。

## 行为与边界

- 服务端能力默认关闭。Composer 显式 `/solve`、`/teach`、`/report` 剥离前缀后提交原题；新 Job 冻结模式、schema、policy，模式参与幂等身份。普通输入及旧 Run 沿用旧语义，不热切换。
- 复用现有 Job、报告、Evidence、final binding 与工作区 SQLite。原答案独立保存，表达 artifact 独立身份/来源版本/追加历史，不改变最终答案或整题审查。
- 本轮采用确定性模板化基础表达：teach/report 明示引用原文及范围，不宣称自动生成高质量讲解。完整讲解生成、图节点与形式化证据深链仍属于 F6 后续增量，不因 S06 通过关闭 #152。
- 只有与原文身份及当前有效审查一致的数学段落可复用其限定等级；数学改写与新增断言保持待验证/新 proposed attempt，不进入已证账本，不提高原答案等级。
- 当前权威来源版本变化使历史表达需重审；写入时核验来源快照，防止整理期间失效后提交成当前。历史版本不可回写迁移。
- 整理失败、超时、断流或表达接口不可用时，原答案可查看；不隐式续算、重发或延长原 deadline。部分完成准确列示已验证范围及未完成义务。
- 公开段落/来源字段白名单，禁止公开凭证、完整 prompt、私有证明或隐藏答案；只读恢复不新增求解调用。异步迟到响应不得跨 Job 或模式覆盖当前 UI。

## 可验证退出条件

绑定与模式幂等、默认关闭及旧 Run、原文/数学改写、来源失效、事务竞争、错误输入、失败回退与部分范围通过公共 API/存储验收；Composer 三入口、原答案/表达切换、刷新身份、竞态与隐私通过真实 Chromium；集中 Standards/Spec 审查修复后冻结源码按工程门禁验收。

当前阶段保持 incomplete，结果及源码/门禁/交接 SHA 由独立验收记录保存。没有真实 provider、独立 rubric 或数学评测，不声明讲解质量或数学能力提升。
