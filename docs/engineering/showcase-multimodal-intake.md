# Showcase 图文读题与基础题型

仅扩展显式工作区。`POST /api/agent/jobs` 使用原有 `message` 与 `input_user_file_id`；可输纯文字、附一张不超过 128 KiB 的 PNG，或两者同时提供。未附图时题干仍须非空，题型按明显描述在本地识别，不加模型调用。图片沿用默认关闭的 `SHOWCASE_VISION_ENABLED`，没有开启时不接受题图。

附图的实时任务先用已配置的求解模型读取题图，使用同一任务预算，再把原文字和读出的题干交给现有求解流程。识读原文仅供内部求解及恢复绑定；公开状态、轨迹和报告不包含识读原文、图片字节或 data URL。工作台显示读图状态及题型。旧的大图附件也不能创建新求解；较小的自定义预算或较长的补充文字仍可能耗尽预算。

读图失败不静默退回纯文字。刷新及原身份重放不再读图，即使附件后来被删除；同一身份更换请求仍会冲突。进程中断时保留原任务和计账，未持久化的读图结果不会在原任务内重发；需显式重新提交新任务。STAR 已有求解检查点的恢复使用与原求解一致的图文题干。类型（计算、方程、不等式、几何、概率统计、证明、未识别）仅作提示，不用于更改推理策略。

普通 Showcase 求解中，若 `python_math` 或 `polynomial_check` 执行超时，仍保留失败记录。模型可以在现有 Job 预算内续答一次，不重跑工具；续答不得将超时描述为工具验证通过。要求验证通过的任务仍走原有复核规则，工具参数校验也保持不变。

验收接缝：真实 Flask 工作区 + 截获的 Intern HTTP、Chromium 普通工作区、官方 baseline 快速检查。覆盖三种输入、读图失败、预算、附件删除后的重复提交、读图中断、公开投影与只读刷新。真实提供方准确性及 #209 的真实实验复验另行登记。
