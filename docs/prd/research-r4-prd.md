# R4 带作用域的可信证据复用 PRD

状态：proposed，开发前可审查规格。日期：2026-10-21。分支：feat/r4-scoped-evidence-reuse。本文件不代表实现或实验完成。

## Problem Statement

重复计算浪费预算，直接复用旧结论又可能忽略前提、定义域或环境变化；普通记忆命中不能代表当前结论仍成立。

## Solution

先实现带前提与版本的确定性工具缓存，支持失效和复核；取得真实证明对象后再研究预算约束的子证明恢复。

比赛用途是可解释系统设计、稳定交互与规范证据；学术价值需要独立实验。官方路径与默认开关遵守 AGENTS.md。

## User Stories

1. 作为数学使用者，我希望改动前提后不会看到过期证据，以便保持可信结果。
2. 作为展示者，我希望恢复任务时能解释哪些成果保留，以便展示连续工作能力。
3. 作为维护者，我希望缓存有版本和范围，以便环境更新后安全失效。
4. 作为实验者，我希望缓存命中和新模型样本分开统计，以便不夸大效率。
5. 作为研究者，我希望和正确实现的普通缓存比较，以便证明优化的增量。
6. 作为实验者，我希望测试题之间不共享生成记忆，以便防止跨题泄漏。
7. 作为维护者，我希望无法可靠提取依赖时采用保守重算，以便不用风险换速度。
8. 作为审查者，我希望没有 Lean 对象时只称工具证据缓存，以便名称与证据一致。

## Implementation Decisions

- 缓存键包含规范化输入、前提/定义域、证据作用域和工具/环境版本，结果只在同一有效作用域下复用。
- 初期只复用确定性结果，跨测试题生成记忆默认关闭；命中不计作新的独立采样。
- 真实证明版本保留实际依赖或保守上界，前提撤销使依赖闭包失效，最终 proof 仍经 kernel 核验。
- 预算优化与普通依赖失效分开开关；依赖抽取、存储和重验全部计成本。

## Testing Decisions

Tool invoke、Run 恢复与 Evidence 报告：捕捉前提变化后的命中/失效及结果范围；不能用随机 DAG 测试代替真实数学收益。

只验证公开行为，外部 API 可注入确定性替身；替身与回放不证明 live 能力。每个切片先有可执行验收，再最小实现和相关回归。实验真值、预算及数据分组遵守总计划，不以自评替代独立评价。

- [ ] 同输入同前提可复用，修改定义域/假设/工具版本后相关证据不得命中。
- [ ] 不能确认依赖时保守重算或重核验，不以无依据的最小依赖优化。
- [ ] 缓存命中不增加成功样本数；跨测试问题不泄漏信息。
- [ ] 缓存关闭后结果协议与原工具相同，官方路径不受影响。

## Out of Scope

- 改变官方 baseline、默认开启研究策略或引入第二个模型服务。
- 一开始就开展大规模 RL、无上限多 Agent 或完整自然语言形式化。
- 以少量演示题的效果宣称普适正确率或理论保证。

## Further Notes

研究假设：真实解题或恢复流程存在足够复用，带作用域的恢复优化在所有维护开销计入后仍超过正确的普通依赖缓存。

近邻边界：STAR 式回溯、HERMES 已验证记忆与一般依赖缓存均为近邻；DAG、失效传播和 top-k 记忆本身不作为学术贡献。

工程保留与停止：真实任务复用不足时关闭缓存；依赖维护吞掉收益时使用更简单策略；优化不胜普通缓存则保留普通缓存，撤下算法主张。

基线：无缓存、相同正确键的普通缓存、LRU/top-k、全失效重算、依赖闭包缓存、其上的预算优化。

评价：无效复用率、真实命中率、最终 kernel/任务通过率、全部维护成本、恢复时延、有效片段保留率与跨前提变更正确性。

依赖：公共 setup S1–S5 的对应能力通过；实际依赖按技术文档中的 ticket 图执行。PR 目标为 develop，默认启用与学术晋升另行判定。
