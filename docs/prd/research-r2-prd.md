# R2 DE 反事实计划与执行控制 PRD

状态：proposed，开发前可审查规格。日期：2026-10-21。分支：feat/r2-de-counterfactual-control。本文件不代表实现或实验完成。

## Problem Statement

失败后继续执行还是改变计划缺乏可核查的判据；仅给轨迹命名为 Discovery 或 Execution 无法证明真正识别了不同状态。

## Solution

在同一可见前缀和同等剩余预算下，比较继续原轨迹、保持计划重新执行、更换核心计划；检查干预是否成立，再比较控制效果。

比赛用途是可解释系统设计、稳定交互与规范证据；学术价值需要独立实验。官方路径与默认开关遵守 AGENTS.md。

## User Stories

1. 作为参赛展示者，我希望系统能解释何时坚持方案和何时换思路，以便展示有意义的规划。
2. 作为实验者，我希望三个动作来自同一个前缀，以便减少难度混淆。
3. 作为实验者，我希望保持计划组确实保留核心构造，以便干预解释成立。
4. 作为审查者，我希望无法判定的策略变化被标为 UNKNOWN，以便避免自评造标签。
5. 作为数学使用者，我希望改计划后仍保留合法证据，以便已有成果不无故丢失。
6. 作为维护者，我希望 DE 表示可以关闭，以便直接动作控制器继续工作。
7. 作为研究者，我希望用独立续写评价动作排序，以便候选选择不自我验证。
8. 作为审查者，我希望了解该状态依赖模型和预算，以便不把它解释为人的真实认知状态。

## Implementation Decisions

- 计划从可见上下文提取，记录关键构造、子目标和约束；不使用标准答案草图。
- 干预有效性由结构化签名和小规模独立审查判断；S2 自评为弱信号，无法判断保留 UNKNOWN。
- 继续、重执行、改计划共享动作执行边界和预算，不再建立互相调用的两个元 Agent。
- DE 是可选表征。先比较相同动作/训练数据的直接 Q 模型，再判断状态层是否有价值。

## Testing Decisions

公开计划及动作请求、Run/Job 报告：捕捉是否真实保持/改变计划、作用域和停止状态；不能从模型自述证明内部认知状态。

只验证公开行为，外部 API 可注入确定性替身；替身与回放不证明 live 能力。每个切片先有可执行验收，再最小实现和相关回归。实验真值、预算及数据分组遵守总计划，不以自评替代独立评价。

- [ ] 同一题同一前缀生成三个动作合同，剩余额度匹配。
- [ ] 保持计划与改计划的判断可审查；不成立的干预不混入确认分析。
- [ ] 分组划分不泄漏；训练动作排序与评估续写相互独立。
- [ ] DE 关闭后可使用直接控制器；不改变官方路径。

## Out of Scope

- 改变官方 baseline、默认开启研究策略或引入第二个模型服务。
- 一开始就开展大规模 RL、无上限多 Agent 或完整自然语言形式化。
- 以少量演示题的效果宣称普适正确率或理论保证。

## Further Notes

研究假设：保持计划与改变计划的干预具有稳定的异质收益，并可由可见前缀预测；DE 表示能提供超出直接动作价值模型的增量。

近邻边界：DE/R-DE 已研究状态和继续/重启；SHAPE、DORA 与预算搜索工作提供可解性和方向分配。去 oracle、加状态名或增加动作本身不作为新贡献。

工程保留与停止：若保持计划组经常暗中换策略，停止采样并修复操作定义；若 DE 不胜直接 Q，保留控制器而撤下状态识别主张；预算不足以辨识差异时记证据不足。

基线：直接 Q(prefix, action)、仅长度/预算/完成状态、固定 continue/restart、同预算多次独立尝试、无 DE 表征的 R1 风格控制器。

评价：预算匹配正确率、独立估计的动作排序与 regret、干预有效率、UNKNOWN 比例、改计划/重执行净收益、跨题型与预算稳定性。

依赖：公共 setup S1–S5 的对应能力通过；实际依赖按技术文档中的 ticket 图执行。PR 目标为 develop，默认启用与学术晋升另行判定。
