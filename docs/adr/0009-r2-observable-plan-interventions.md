# R2 DE 反事实计划与执行控制 的边界决策

状态：proposed。日期：2026-10-21。范围：feat/r2-de-counterfactual-control。

Discovery/Execution 采用相对于固定模型、预算及参考动作的操作性定义；不主张读取内部认知状态。保持计划与改变计划必须经独立可观察检查，UNKNOWN 不强制分类。这增加审查成本，但防止由提示措辞或自评产生虚假的干预差异。

该决策服从 ADR-0001 的官方隔离及 ADR-0007 的计量合同。默认关闭；工程能力可保留、Showcase 启用和学术主张分别验收。相关接口、实验与撤回条件见该方向技术文档。
