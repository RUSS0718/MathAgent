# ADR-0014：完整 STAR 产品路径的状态职责与安全恢复

状态：accepted；用户已确认职责、恢复原则和整体交付合同。日期：2026-10-23。实施入口：[完整 STAR 产品 spec #56](https://github.com/RUSS0718/MathAgent/issues/56)。

当前 Solver Harness 与 Workbench 控制链尚未贯通。为整合 ADR-0002 的执行控制和 ADR-0013 的数学状态权威，Solver 快照保存数学进展，现有 S3 控制栅栏及唯一账本决定动作是否获准执行、终止与资源消耗；Job 投影公开状态，LangGraph checkpoint 保存执行位置并关联对应状态版本，不作为第二份可独立改写的数学账本。所有对象关联同一任务身份，新增 STAR 路径不能绕过 S3 或重置累计额度。

已持久化的完成动作与已接受步骤必须在恢复后复用。例如第二步已接受后进程退出，重启应从第三步继续，沿用原预算与 deadline。远端请求已发出而结果不明时保留 unknown_outcome、预留与调用身份，进入 needs_review；后续处置必须显式决定，不能把自动重发称为续算。

未知调用的重试由用户通过产品界面显式选择，Meta 可以提出建议；重试产生新调用 ID，继续使用原账本，保留旧请求的未知消耗。项目真实验收已有用户授权，不再重复请求 API 调用许可；这一授权不代替产品内对单个未知请求的重试决策。

选择分别拥有数学状态和执行控制职责，保留现有产品合同；拒绝由 Job、Solver 快照和 checkpoint 各自维护可独立覆盖的完整状态。代价是需要验证跨状态版本的提交、动作记录与恢复位置的一致性。该一致性必须通过公共 Job/Run 接口的中断、取消、迟到结果与重启验收，不能仅用快照读取测试证明。
