# 实验边界与共享计量合同

状态：proposed。日期：2026-10-21。依据：用户要求在 develop 上进行五方向实验并服务比赛主观评测；沿用 ADR-0001 的官方隔离边界。

实验只通过显式 research 或 showcase 入口运行，所有新增策略默认关闭，唯一模型服务为 Intern S2。官方 baseline 的文件、行为和预算继续冻结；通用可靠性修复先形成 B-ready，算法比较固定该版本。

项目消耗、策略部署消耗与确定性工具成本分别记账。每次请求预留额度，所有重试、恢复与并发 worker 共用账本；usage 缺失表示未知，不能记为免费。未获得服务方计量与价格口径前，不宣称本地输出参数等于金额或隐藏推理的硬上限。

选择统一现有 Run/Job 与 Adapter 边界，而非新建第二套 Agent 框架，可保留现有展示与测试合同，但需要先修复跨 Run 计数、计量传递、取消调度与最终证据绑定。运行 raw 保持 ignored，分支保存协议、脱敏汇总和外部证据索引。该文件记录拟实施决策，不表示账本与修复已经完成。

执行状态归属遵循 ADR-0002：LangGraph 管理 Run 执行与 checkpoint，Workspace Job 作为控制入口和状态投影，现有 LiveAgentPipeline 策略逐步通过适配接入。预算账本只设一个权威来源。该迁移先过 S3 的中断与恢复风险验证；未通过时公开标记恢复不可用或需要复核，不能用事件重放冒充执行恢复。
