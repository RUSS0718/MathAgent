## 离线验收命令

```powershell
python scripts/check.py --offline
python scripts/check_showcase_release.py
```

离线验收只证明工程合同、状态机、工具边界、脱敏和官方导入边界可达，不证明真实模型推理效果。

## Live 验收前置条件

复制 [.env.example](../../.env.example) 为本地未跟踪的 `.env`，填写 `INTERN_API_KEY`，必要时调整 `INTERN_API_BASE` 和 `INTERN_MODEL`。真实配置不得提交到 Git。

Live 验收至少记录：

1. 一条文本题 Run；
2. 一次模型请求工具的 Run；
3. 一次工具失败、checkpoint 和 resume；
4. 一条文字加 PNG 的 Vision Run 或明确的 unavailable；
5. 模型 ID、状态、耗时、预算和 Evidence Pack 摘要。

Live 结果写入被忽略的 `artifacts/<run_id>/`，只把脱敏结论和可复现实验命令写回本文件或独立报告。
