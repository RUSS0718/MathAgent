## 边界与脱敏

- `user_agent.py`、`implementations/`、`BASELINE.json` 和官方默认请求预算保持冻结；官方导入不得加载 `showcase`。
- trace、SSE、Evidence 和 replay 只允许脱敏步骤、状态、摘要和引用；禁止凭证、完整 prompt、隐藏答案、隐藏推理、个人信息和完整图片。
- `polynomial_check` 的 `candidate_status` 与 `coverage_status` 分开；`pass` 仅表示候选在工具适用域内通过，不能写成完整解集证明。
- `replay` 只读 Evidence Pack，不触发模型或工具；`PythonMathTool` 仍是显式开启的 `experimental` 工具。
