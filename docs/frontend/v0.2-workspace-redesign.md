# v0.2 MathAgent 工作区视觉重设计

**状态：** accepted for the current v0.2 Showcase branch

## 视觉基线

本次工作区采用 MIT 许可的 LangChain Agent Chat UI 作为聊天交互基线，参考它的消息流、工具调用、Artifact 侧栏和运行态布局；OpenHands 的运行状态和工具活动表达只作为视觉参考，不搬入代码 Agent 专属的终端、文件树和浏览器工作区。

参考项目：

- https://github.com/langchain-ai/agent-chat-ui
- https://github.com/OpenHands/OpenHands

MathAgent 仍使用 Vue 3 + Vite + Pinia，不引入 Next.js。后端 API、SSE、Session、Job、Report 和官方路径保持不变。

## 页面合同

- 左侧：MathAgent 品牌、当前会话、新建会话、设置入口。
- 中间：题目消息、中文数学报告、底部输入栏；空状态提供数学任务示例。
- 右侧：运行状态、Agent 节点时间线、验证状态和工具摘要；没有 Job 时显示说明卡。
- Job 运行时：显示 queued/running/waiting_input/failed/succeeded；节点事件按 `intake`、`planner`、`solver`、`tool`、`verifier`、`synthesizer`、`terminal` 聚合。
- 小屏：左侧和右侧面板变为可折叠区域，中间对话保持完整可用。

## 视觉原则

- 使用中性浅色表面、深色正文和单一蓝绿色强调色，避免渐变和大面积装饰。
- 运行态使用文字、图标和状态点同时表达，不只依赖颜色。
- 保留键盘可达按钮、语义标题、`aria-live` 消息区和清晰的空/失败状态。
- 公开答案使用安全 Markdown + KaTeX；完整提示、隐藏推理和凭证继续留在公开边界之外。
