# 16: 流式中断、未知结果与恢复

**What to build:** 模型流式调用中断时保存部分文本和调用身份，但不会把部分文本当成完成；未知远端结果不重复计费或重复提交。

**Blocked by:** #12

**Status:** ready-for-agent

**Acceptance criteria:**

- [ ] 部分输出与工具错误被持久化，状态保持可恢复而非完成。
- [ ] 重试使用可追踪的唯一 `call_id`，已提交结果不重复写入。
- [ ] 已发出但结果未知的请求标记 `unknown_outcome`。
- [ ] 未知结果不被记为零成本、成功或可安全重放。
- [ ] 迟到响应不能覆盖已冻结终态。
- [ ] 支持 STAR AC-32、STAR AC-43 的中断、未知结果与审计边界。
